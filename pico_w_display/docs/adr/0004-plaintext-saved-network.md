# Saved Network password stored in plaintext flash

The Saved Network's Wi-Fi password is persisted in plaintext in the `SETTINGS_STORAGE` flash region, so the device can Rejoin after a power cycle with no client involved. Anyone with physical access can read it back out — holding BOOTSEL and dumping flash with `picotool`, or over SWD. We accept that under ADR-0002's threat model: a device on the owner's own desk and network, not one resisting an attacker who can already pick it up. The alternatives don't change that: encrypting with a key that also lives in flash protects nothing, obfuscating with a device-unique ID only defeats a casual `strings` dump (and would read as protection it isn't), and a real secret — an OTP-held key with secure boot so it can't simply be read by other firmware — is a separate, much larger project. The password is still never logged or sent back to a client, and `FORGET` removes it.
